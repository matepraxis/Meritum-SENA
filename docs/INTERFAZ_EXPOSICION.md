# Interfaz de la versión de exposición

## Idea visual

Meritum-SENA tiene una identidad gráfica independiente del Meritum institucional. Usa un encabezado sobrio, acentos verde petróleo y amarillo, y una distribución adaptable al celular y a una pantalla de exposición. No necesita librerías visuales, imágenes externas ni Internet adicional para cargar estilos.

## Recorrido sugerido

1. Ingresar como **docente** y mostrar las tres opciones: otorgar Boscoins, crear recompensa y publicar anuncio.
2. Abrir el historial para comprobar el movimiento generado.
3. Cambiar a la cuenta ficticia de **estudiante** y mostrar el saldo.
4. Abrir BoscoMarket, explicar la disponibilidad y hacer un canje válido.
5. Mostrar el historial y las publicaciones.
6. Repetir desde celular o con un navegador estrecho para demostrar la adaptación.

## Diseño accesible

- Navegación con enlaces convencionales y secciones identificadas.
- Botones grandes para pantallas táctiles.
- Estados de canje deshabilitados cuando no hay puntos o inventario.
- Etiquetas de campos y avisos legibles.
- Sin animaciones necesarias para comprender el sistema.
- Cambio de roles en sesiones separadas del navegador para evitar confusiones durante la exposición.

**Límite:** no incorpora funciones nuevas de negocio. El rediseño es de presentación y navegación; los permisos siguen verificándose en Django.
