# Retirar la demo sin afectar Meritum institucional

Meritum-SENA es temporal. Al finalizar la muestra:

1. Confirmar que el equipo tiene sus evidencias de la exposición.
2. En Render, buscar el servicio **meritum-sena-demo** y verificar que el repositorio conectado sea **matepraxis/Meritum-SENA**.
3. Suspender o eliminar únicamente ese servicio.
4. Revisar si existe **meritum-sena-demo-db**, una base de datos de prueba independiente; si no se utiliza, retirarla también.
5. Conservar el código y documentación en GitHub para la sustentación.
6. Verificar que la plataforma y base institucional **meritum-pilot** y **meritum-pilot-db** continúan intactas.

No se automatizan acciones de borrado: antes de eliminar algo, se debe identificar y confirmar el recurso exacto.
